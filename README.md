🔐 Password Buddy — Smart Password Generator & Strength Checker
Password Buddy is a friendly and powerful GUI application built using Python (Tkinter).
It helps users create strong, memorable, and secure passwords while also checking their strength, estimating crack time, and detecting common breached passwords.

✨ Features
🔑 Smart Password Generator
Generates three styles of passwords:
Hybrid style — based on your name, favorite person, color, number
Memorable word-based style — uses custom words
Strong random password
Each suggestion shows:
Strength rating (Weak / Moderate / Strong)
Copy button

🔍 Password Strength Checker
Real-time entropy calculation
Strength visualization with a progress bar
Time-to-crack estimation at 1e9 guesses/sec
Mock breach detection (using common breached passwords list)

🎨 Modern UI
Clean Tkinter interface
Dark / Light mode toggle
Password visibility show/hide eye button

📜 Password History
Automatically stores copied passwords in session
View history in a popup window
Export history to .txt
Clear history anytime

📦 Installation
Requirements
Python 3.8+
Tkinter (comes with most Python installations)
